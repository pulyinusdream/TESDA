# NTTC Block 3.2 — Official IWER Reference Materials

## Objective
Add optional applicant access to the official TESDA issuances that support the IWER guidance shown in the NTTC online pre-screening module.

## Production path
`public/apps/nttc/`

## Reference files bundled
- `References/TESDA_Circular_033_s2017_IWER.pdf` — Primary IWER credit-equivalency guideline.
- `References/TESDA_Circular_050_s2017_RPIIT.pdf` — Regional Program on Industry Immersion of Trainers.
- `References/TESDA_Circular_051_s2017_Equivalent_IWER.pdf` — Equivalent IWER credits using teaching experience and other modalities.
- `References/TESDA_Circular_020_s2014_NTTC_Level_I.pdf` — Supporting NTTC Level I guideline.

Applicants are not required to read these documents. The page continues to provide plain-language guidance. Links open the official reference copies in a new browser tab.
